# Inspiração visual — Folhetos FNP

Esta pasta guarda as referências visuais que definem a identidade do sistema de folhetos.
Todo folheto novo deve respeitar essa linguagem — apenas dados e textos mudam.

## Arquivos esperados

Arraste/salve as imagens nesta pasta com os nomes exatos abaixo:

| Arquivo                          | Conteúdo                                                       | Origem                       |
|----------------------------------|----------------------------------------------------------------|------------------------------|
| `alfabeto-modular-foto.png`      | Alfabeto construído sobre módulos quadrados, **preenchido com foto** (letras-janela) | Referência inicial enviada   |
| `alfabeto-modular-contorno.png`  | Mesmo alfabeto em **contorno colorido** (azul/verde/amarelo)   | Variante outline             |
| `padrao-geometrico-cosip.png`    | Grade modular usada na capa COSIP (quadrados + ¼ de círculo)   | PDF COSIP, capa              |
| `capa-cosip.png`                 | Capa do folheto COSIP — exemplo canônico de aplicação          | PDF COSIP, página 1          |
| `cosip-folheto-completo.pdf`     | PDF original do folheto COSIP (16 páginas)                     | Referência canônica          |

## Como usar estas referências

1. **Alfabeto modular** → inspiração tipográfica para títulos de capa e divisórias de seção. Não é fonte instalável; é um vocabulário de formas (quadrado, ½ círculo, ¼ de círculo) que pode ser reproduzido como ilustração quando um título precisar de tratamento especial.

2. **Padrão geométrico COSIP** → usado como elemento gráfico recorrente em:
   - rodapé das páginas internas (faixa lateral azul + módulos)
   - fundo de páginas divisórias
   - decoração de capa quando não houver foto

3. **Capa COSIP** → modelo de composição: foto recortada nos módulos da grade + título + subtítulo + logo FNP centralizado.

> Para detalhes técnicos (paleta exata, tipografia, grid, componentes de página), ver [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md).
